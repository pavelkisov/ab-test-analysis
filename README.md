# A/B Test Analysis — Statistical Significance

Полноценный статистический анализ A/B-теста через **scipy.stats**:
Welch's t-test, z-test для пропорций, 95% доверительный интервал, effect size (Cohen's h).

## Сценарий

A/B-тест нового алгоритма рекомендаций на лендинге интернет-магазина.
- **Группа A** (контроль): старый лендинг
- **Группа B** (тест): новый алгоритм рекомендаций
- **Метрика:** бинарная конверсия в покупку (0/1)
- **Размер:** 5 000 + 5 000 пользователей

## Данные

Синтетические данные сгенерированы через `numpy.random.binomial(seed=42)` для воспроизводимости.
Это честный подход для демонстрации статистических методов — реальные данные A/B-тестов компаний
не публикуются. Если у тебя есть свой датасет A/B-теста — замени генерацию в `ab_test_analysis.py`
на чтение CSV, остальной код останется без изменений.

## Что считается

1. Конверсии в группах A и B
2. **Welch's t-test** через `scipy.stats.ttest_ind(equal_var=False)` — корректно для бинарных данных
3. **Z-test для пропорций** — вручную через pooled standard error
4. **95% доверительный интервал** для разницы конверсий (Wald)
5. **Effect size** — Cohen's h
6. Вывод: статистически значимо или нет (α = 0.05)

## Результаты (фактические)

| Метрика | Значение |
|---|---|
| Конверсия A | 4.20% (210 / 5000) |
| Конверсия B | 5.42% (271 / 5000) |
| Абсолютный прирост | +1.22 п.п. |
| Относительный прирост | +29.0% |
| p-value (two-sided) | **0.0044** |
| 95% CI для разницы | [0.38%, 2.06%] |
| Cohen's h | 0.057 |
| Вывод | ✅ Статистически значимо (p < 0.05) |

Полные результаты — в `results/ab-test-real-results.json`.

## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python ab_test_analysis.py
```

В конце скрипт выведет полный статистический отчёт в консоль и сохранит JSON в `results/`.
