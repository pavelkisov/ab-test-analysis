# A/B Test Analysis — Statistical Significance

Полноценный статистический анализ A/B-теста: **z-test для пропорций** (основной метод),
Welch's t-test (перекрёстная проверка), 95% доверительный интервал, effect size (Cohen's h),
плюс ноутбук с визуализацией результата.

## Сценарий

A/B-тест нового алгоритма рекомендаций на лендинге интернет-магазина.
- **Группа A** (контроль): старый лендинг
- **Группа B** (тест): новый алгоритм рекомендаций
- **Метрика:** бинарная конверсия в покупку (0/1)
- **Размер:** 5 000 + 5 000 пользователей

## Данные: что синтетического и почему

Данные сгенерированы через `numpy.random.binomial(seed=42)` — воспроизводимо и
без искажений. **Что это значит честно:**

- **Реально в проекте:** методология и выводы — z-test для пропорций, доверительные
  интервалы, effect size, различение статистической и практической значимости,
  готовность принимать решение по тесту. Именно это и проверяется в работе.
- **Синтетическое:** сами конверсии. Реальные данные A/B-тестов компаний не
  публикуются (коммерческая тайна), поэтому публично «настоящего» A/B-датасета
  с известным правильным ответом не существует — любой рабочий пример либо
  синтетический, либо из игры с открытой статистикой (Cookie Cats и т.п.).
- **Как применить к своим данным:** скрипт принимает любой CSV с колонками
  `group` и `converted` — замените блок генерации на `pd.read_csv`, остальной код
  не меняется.

Это осознанное ограничение пет-проекта, а не попытка выдать симуляцию за
производственный опыт. На собеседовании я так и рассказываю: метод — боевой,
данные — учебные.

## Статистические методы

| Метод | Роль | Почему |
|---|---|---|
| **Z-test для пропорций** | основной | канонический метод для бинарной конверсии; использует pooled standard error |
| Welch's t-test (`scipy.stats.ttest_ind`, `equal_var=False`) | перекрёстная проверка | асимптотически эквивалентен z-test при больших n; приводится для полноты |
| 95% CI для разницы (Wald) | оценка величины эффекта | показывает диапазон истинного прироста |
| Cohen's h | effect size | стандартизованная величина эффекта для пропорций |

> **Важно про выбор метода.** Для бинарной конверсии (0/1) каноничный тест —
> **z-test для пропорций**, а не t-test. Welch's t-test на бинарных исходах даёт
> приемлемую оценку, но не является «более корректным». При больших n (здесь
> 5 000+5 000) оба теста дают практически одинаковые p-value.

## Результаты (фактические)

| Метрика | Значение |
|---|---|
| Конверсия A (контроль) | 4.20% (210 / 5000) |
| Конверсия B (тест) | 5.42% (271 / 5000) |
| Абсолютный прирост | +1.22 п.п. |
| Относительный прирост | +29.0% |
| p-value (z-test, two-sided) | **0.0044** |
| p-value (Welch's t-test, two-sided) | 0.0044 (перекрёстная проверка) |
| 95% CI для разницы | [0.38%, 2.06%] |
| Cohen's h | 0.057 (малый эффект) |
| Вывод | ✅ Статистически значимо (p < 0.05) |

Полные результаты — в `results/ab-test-real-results.json`.

## Практическая значимость (отдельно от статистической)

При размере групп 5 000+5 000 статистическая значимость достигается даже при
**малом effect size** (Cohen's h = 0.057). Это значит, что разница в конверсии
реально существует, но **решение о раскатке** нужно принимать с учётом
практической значимости: окупит ли прирост +1.22 п.п. стоимость разработки и
поддержки нового алгоритма. На собеседовании по A/B-тестированию именно этот
различение statistical vs practical significance чаще всего и проверяют.

## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python ab_test_analysis.py   # полный расчёт
jupyter notebook ab_test_viz.ipynb   # визуализация (опционально)
```

Скрипт пишет результаты в `results/ab-test-real-results.json` (путь относительный).
